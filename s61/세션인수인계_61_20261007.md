## 3. 작업 환경 메모
- 이 환경에는 맑은 고딕이 없음. Noto Sans CJK KR(Regular·Bold·Medium)을 GitHub raw에서 받아 ~/.fonts에 두고 fontconfig alias(맑은 고딕 → Noto Sans CJK KR)로 렌더. 3번 그림 글자도 Noto Sans CJK KR Bold/Regular로 그림.
